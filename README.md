# 🟧 Project Description:

   **DeliTrack** is console program that shows how a delivery courier will handle orders and driver routes.In real situations couriers face, inaccurate pickup locations, data errors, and missed scheduled windows cause delivery delays, and buyers end up with misleading ETAs. The new orders will go to the back of the queue so they are always processed in the order that they arrived and every order is also saved in a list and a hash table that it can be found almost instantly by tracking number. To see orders for a certain date, area, or time range, the program sorts them with the merge sort and then uses  the binary search to find the matches. A driver’s route is kept as a linked list, so an urgent pickup can be added or a cancelled order removed mid-route without rebuilding it and a built-in speed checker times the main operations with 100 to 100,000 orders to show how each data structure scales. DeliTrack is console-only and made for a single user (the dispatcher), keeps data in memory so orders are lost when the program closes, and does not use GPS or maps or find the shortest route, so its ETAs are only as accurate as the scheduled times is entered.
